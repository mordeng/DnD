# Chapter Template

Use this structure for every chapter. Not every section needs equal weight -- adapt to the chapter's purpose.

---

## Pre-Writing Checklist

- [ ] Read previous chapter's ending (match the hook)
- [ ] Check `../tracking/character-state.md` for current physical/emotional states
- [ ] Check `../tracking/plot-threads.md` for threads due for advancement
- [ ] Check `../tracking/consistency-tracker.md` for running gags due for callback
- [ ] Review this chapter's entry in the volume plan
- [ ] Identify: What is this chapter's ONE essential job? (advance plot / deepen character / reveal information / provide catharsis)

---

## Chapter Structure

### Opening Hook (First ~200 words)

Choose ONE opener type:
- **Action**: Drop into a moment of motion or danger
- **Observation**: The narrator or a character notices something funny/strange/alarming
- **Callback**: Reference to a previous event that recontextualizes it
- **Blue Box**: Guide entry, alchemist's note, or letter (Volume 3 especially)

The opening should make the reader want the NEXT paragraph, not summarize what's coming.

### Scene 1 (Primary)

| Element | Description |
|---------|-------------|
| **Setting** | Where are we? One sensory detail that grounds the reader. |
| **Characters present** | Who's in the scene? What are they doing when we arrive? |
| **Goal** | What does the focal character want in this scene? |
| **Obstacle** | What prevents the goal? |
| **Outcome** | Yes-but (success with complication) or No-and (failure with escalation) |
| **Humor beat** | At least one moment of genuine humor |
| **Character moment** | At least one moment where a character feels real |

### Scene Transition

Use one of:
- `* * *` (scene break with time/location skip)
- Narrative bridge (narrator reflects, connecting scenes thematically)
- Direct continuation (no break needed if same time/place)

### Scene 2 (Secondary, if needed)

Same structure as Scene 1. Typically serves a different purpose:
- If Scene 1 is plot, Scene 2 is character
- If Scene 1 is action, Scene 2 is reflection
- If Scene 1 is funny, Scene 2 earns the emotional beat

### Closing Hook (Final ~200 words)

Choose ONE closer type:
- **Revelation**: New information that changes the reader's understanding
- **Question**: A mystery posed or deepened
- **Emotional punch + deflection**: A genuine moment followed by the narrator or a character deflecting with humor
- **Cliffhanger**: Danger, arrival, or decision point (use sparingly -- not every chapter)

The final line should make the reader turn the page, not feel satisfied.

## Post-Writing Checklist

- [ ] **Word count**: 2,000-3,500 words (target 2,500)
- [ ] **Paragraph length**: No paragraph exceeds 80 words
- [ ] **Humor**: At least one genuine laugh beat
- [ ] **Emotion**: At least one genuine emotional beat
- [ ] **Hook**: Chapter ends with a forward-pulling hook
- [ ] **Distinct voices**: Each speaking character sounds like themselves (cover names, read dialogue alone)
- [ ] **Blue boxes**: 2-4 per chapter, never containing plot-critical-only information
- [ ] **No D&D mechanics**: No spell slots, levels, AC, hit points
- [ ] **Show don't tell**: Emotions shown through behavior, not stated

### Update Tracking Files

- [ ] `../tracking/character-state.md` -- Update physical/emotional states
- [ ] `../tracking/plot-threads.md` -- Mark threads advanced, add new ones
- [ ] `../tracking/consistency-tracker.md` -- Log gag uses, foreshadowing, Chekhov's guns

### Author's Note Draft

Write 100-200 words for the Royal Road author's note:
- Behind-the-scenes tidbit (what inspired the chapter, a challenge faced)
- Reader engagement question
- Tease for next chapter (without spoiling)
- Keep the tone conversational and warm
